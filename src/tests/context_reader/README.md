# 独立来源上下文判读实验

cases40.json 在 reader 实现及推理前按原文选题冻结，frozen.json 保存其 SHA-256。
摘要统一以UTF-8/LF字节计算，避免Git在Windows/Linux之间转换换行造成误报；
同时保留初次运行的Windows原始文件摘要，题目、答案与出处内容不变。
20 人、40 题；每组一个可回答题与一个事件／角色／错误前提／证据不足对照。
开发 6 人 12 题，留出 14 人 28 题；同人、同篇章不得跨组。
这是有目的选取的来源条件验收集，非随机、非第三方盲标，不能声称覆盖所有朝代君主。
prior_overlap.json 另记录旧测试的同名人物：本轮留出14人中6人曾出现在旧JSON样本；
只有8人16题在该有限扫描中未发现同名，仍不宣称严格盲测。8题模型先导不含已检测重叠人物。
历史原文按保存的维基文库修订版本理解，不把史书记载等同于经考证的历史事实。

每题固定一个原文候选ID，三策略完全复用：A 原有片段+规则，B 恢复原文上下文+相同规则，
C 相同恢复上下文+本地指令模型。C 原始判断、结构校验、逐字引用校验分别保存。
不能把引用存在当作语义正确；人工复核还需核对回答内容、人物、事件、对象和来源归属。

负例的 not_supported 表示该来源不能支持题目的错误前提或过度推断，不表示整部语料库无答案。
引述和转述可回答“谁说了什么”，不能升级为事情已经属实。相邻事件不能混用原因。
本实验只测条件证据判断，不测真实召回、候选排序或 Top5；相关报告字段为 null。
下一步真实入口需先保存检索候选快照，再用完全相同的候选做三路判断，禁止偷偷加入 gold。

从 src 执行：

```
python -B -X utf8 -m unittest tests.test_evidence_reader
python -B -X utf8 -m tests.context_reader.run
python -B -X utf8 -m tests.context_reader.run --model-pilot --output data/evidence-reader/abc-pilot.json
```

第三条仅为预先固定的8题：陈平、邓禹（开发）；王维、宋濂（留出），每人正反两题。
其余32题的C策略未测，不可写通过。模型仅由显式实验命令启动，退出时关闭自有进程。
