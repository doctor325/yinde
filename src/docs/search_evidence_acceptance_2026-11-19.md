# 默认史料搜索与证据核对验收

2026-11-19，以 `17ed630` 的搜索后端为基线。此轮测两个结果。第一，用户能否在前五条读到足以作答的材料。第二，系统标出的证据线索及具体归因能否由原文和上下文支撑。

## 样本与判据

运行前从 `existing17.json`、`causal7.json` 和 `causal_independent6.json` 固定九个已有问题，七个可回答问题和两个对照。样本覆盖时间、地点、官职、动作对象、史家归因、本人自述、拒绝征召。所有问题都曾用于开发或验证，本轮属于回归验收。

按默认提问路径使用正式库、标点索引、本地语义召回和真实重排。以前五条命中片段及同版本的相邻原文为检读范围。只要有一份原文足以支持所问内容，该题的前五条检索即通过，平行史料也计入。对照题记录题设是否得到错误支持。随后核对每题展示的二十条中所有被标为线索齐全的结果和结构化因果说明，检查人物、动作、对象、事件状态、所问细节和陈述来源。展示的命中、上下文和固定参考都与本机标点索引核对了原文、分段位置、页号、修订版本、来源 URL 及哈希。

## 前五条检索与证据标记

- 七道可回答题均在前五条找到足够原文，且最先出现的可用证据都在第1条。指定片段有六条第1、一条第2。单看重排模型，李靖指定片段在第10，陶潜指定片段在第7，二者经证据规则调整后进入前五。
- 九题共展示180条。八条被标作线索齐全，所核对的八条均有原文支持，其中李靖占两条。两条单独的因果说明也有依据，分别来自史家评论和人物自述。两个对照没有错误标记。该比例只适用于本轮所审内容。
- 规则仍会漏掉可用平行材料。例如《宋书》和《南史》关于陶潜拒见督邮、自述并解印去职的两条记载已在第4和第5条，仍显示线索不足。李密第2条的奏表也需要结合传记上下文才能读出证据链。这些材料可以阅读，规则对单个片段的判定更保守。
- 单次顺序运行的后端中位耗时14.63秒，范围4.83至70.17秒。包拯题总耗时70.17秒，其中证据管线65.47秒，管线内重排耗时12.05秒。后续若要定位慢查询，可从重排之外的候选检查和上下文装配计时入手。

## 自动回答交付边界

默认搜索在九题中生成调用为零。页面给出史料和检索线索，自动撰写的历史结论在这一路径上没有可统计的样本。既有本地生成验收中，gpt-oss-20b 在首题把“杖劎亡”读作死亡，与后文陈平到修武降汉矛盾，按冻结规则停止。其余一条开发反例和六条留出题仍未触发。默认检索达到本轮样本标准，自动回答仍未达到交付标准。见 [本地模型判读验收](harmony_history_comparison.md)。
