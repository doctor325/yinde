# 待核实说法与原文事件分离实验

2026-11-15，基于6748ba6。隔离v4实验，不改变v3失败记录或默认检索。

## 本轮修改

- 问题解析保留open/verify及proposed_answer；核实题的待核实内容要求逐字出自问题，
  并随原问题进入下一步。该字段不是史实或gold。
- 判读先输出source_event，再输出comparison，最后给出判断与解释。原文中的人物、
  动作、对象、属性采用短语摘录，各有引用；拒任/离开及叙述/指控等类别补充明确含义。
- 守卫检查原文短语是否实际出现在该字段引用的单元中；对象错配或所提说法无依据不能被
  matched接纳。insufficient必须空答案。仍保留semantic_verified=false：角色、别名、
  状态、来源及解释是否正确需要语义复核，字符串出现本身不证明归属。
- 同一个本机4B模型，两步调用、180/650输出token上限和120秒请求期限不变。
  使用上轮已核对的370字/15单元窗口，不重新查库或选句；问题、gold、原文、编号、
  省略范围保持一致。新目录保留baseline路径/hash及各阶段输出。

## 推理前固定的验收标准

仍只复测已曝光开发正反题，不测留出题，不接入搜索，不更新桌面包。

正题须满足：人物与离开项王事件对应；核心原因是惧诛；实际离开为departed；
来源为narrator；各字段原文引用成立；解释没有额外误读。全部满足才通过。

反题须保留待验证的原因和魏王对象；从原文提取的离项王事件不可改写为离魏王；
应明确缺乏同一事件依据、用insufficient并保持空答案，解释与对象引用也必须正确。
不能仅以eligible=false当作通过。较早离魏记载仍在省略区，不宣称已比较两段完整记载。

这两题已用于开发，任何改善都不构成独立泛化证明。不得修改gold或挑选重跑结果。
