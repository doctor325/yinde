# 六朝新人物搜索验收

2026-11-19，生产搜索基线 `53af159`。本轮在检索前从本机只读标点索引核对了六个历史时期的六位人物，再为其中两件事设置反例。题目、可支持结论、来源版本和原文偏移在 [冻结题集](../tests/evidence_acceptance/search_holdout8.json) 中。选择依据是不同的事件结构与可核对史料，属于目的抽样。六位人物未在既有测试与开发文档的姓名检索中出现。两道反例复用正例的事件，八题对应六位人物。

每题使用实际默认搜索表单提交一次。Node 驱动代替浏览器 DOM，运行实际搜索路由、请求代码和结果渲染，通过本机桌面服务提交给正式 API、标点索引与本地模型。驱动逐题确认页面渲染顺序和 API 命中顺序一致。每题呈现20条，核对前五及相邻上下文，查看候选诊断以区分入池与排序，检查展示范围内的线索标记和因果说明。平行史料按相同的事实要求计分。

## 优先级

六道正例中，**两题从前五条打开原文可作答**。若要求仅凭前五条及卡片相邻文字即可作答，**一题通过**，袁崇焕一题缺明确年号。四道正例的关键证据未进入重排候选，优先修复问题解析与召回。上述判断限定在已记录的候选及核对的可替代文本，候选诊断记录的是进入重排的集合。

160条展示结果里线索齐全标记为0，结构化因果说明为0。两道反例未被错误确认，杨业、袁崇焕的有效材料也被漏标。有效原文能排前列时，第二优先是让证据判断识别被俘、刑死和有出处的时间锚点，同时继续验证同名、其他受事和跨事件错配。

第一项具体开发应区分人物、动作、对象和所问维度，把现代长谓语从硬性的字面线索中拆出来，允许明确对应的史书动作表达进入召回。没有全名的记载可沿有出处的本传范围找事件，事件归属仍须逐段检验。验收先看足以作答的原文能否进入重排，再看前五与反例误标。八题转为后续回归样本，另用未看结果的材料检查推广性。

八题提交到结果渲染的中位数为11.35秒，范围3.18至20.24秒。首题包含冷启动，后端总耗时20.19秒，其中证据管线14.81秒、重排7.77秒。上轮包拯的70.17秒仍单独记录，本轮的陌生问题结果支持先投入召回。
