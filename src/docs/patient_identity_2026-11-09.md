# 人物称谓与事件受事来源依据

先选来源再实现：白公9270、焦朗45022、传圭228312三处独立真实正例，均不在固定17题开发集内，保存原文、页、修订号、来源哈希于patient_sources.json。它们支持同主语“攻某人，杀之”中的直接受事，不代表所有指代类型。此前关羽/邓艾/韩信真实负例继续参与测试。

patient_references.appellations要求候选标题精确对应所问人物；同页、同版本、同source_sha256、同heading/body的开篇“称谓者……名某……”提供称谓关联，且姓名后缀匹配原文明示名，冲突称谓不输出。关联带开篇原句、偏移、chunk和适用范围。来源依据不能扩为跨书/跨版本全局别名；并不等于独立历史身份数据库。

受事观察只接受攻/捕/执后紧跟唯一明确目标、逗号后同主语杀之的闭合结构；记录patient角色、之及前置目标的原文位置、候选和施事排除理由。引述、否定、意愿、命令、插入其他人物或动作不确认。不以最近名词作为受事。当前没有解析换主语后的“击走之”，祖逖仍未解决。

接入现有证据审计，在已进入候选的页面内读取称谓依据，不修改语料、召回算法或模型。商鞅9870“秦發兵攻商君，殺之於鄭黽池”通过真实库只读审计，由未确认变为clues_present；池补入原有地点表面后缀。该结果只证明此处来源引用与局部受事审计改善，没有重跑模型排名，不宣称完整回答准确率。

验证预算3条：首轮1失败来自新增合成用例预期写反（有完整称谓依据的正例本应确认），纠正新增断言而未改旧gold；第二轮原文验证暴露地点后缀不含池，第三轮补齐后9项全部通过。三处独立真实正例、三处旧真实负例、合成反转/引述/否定/换主体及旧结构对照均包含在范围中。独立正例只覆盖一类局部受事，不覆盖称谓抽取的独立正例或跨主语指代。

整类验收仍未通过：别号抽取目前只覆盖有限开篇形式、标题缺失/异名/多人同名尚需更完整资料；跨主语击走之、复杂之/其与引用嵌套仍无可靠通用解析。不能宣称本轮把人物身份与指代做完。既有源码采用的规则在这些边界上需要更强上下文理解的实验，而不是不断放开本规则。

正式库、原始史料、模型和桌面包未改。已达到3条验证预算且整类验收不成立，桌面构建与装配验证未执行。后续桌面更新须对这一轮有限能力如实标注，并另安排产物装配检查；不能拿本轮单测当桌面验证。公开发布和CI未执行。
