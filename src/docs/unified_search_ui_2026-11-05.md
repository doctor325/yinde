# 统一搜索入口

首页以同一个搜索框接受人物、事件、原文和问题，移除语义实验/原底本问答两个分支入口。标点搜索页统一标题、输入和提交动作；史书范围与原底本对照收进“检索选项”，移除五种技术模式选择器。旧semantic/history-qa/ask入口在本机标点服务可用时使用同一表单；显式原底本来源入口仍可对照，静态演示保留既有能力。

用户未指定旧模式时，通用问句/关系表达选择现有expanded检索，其他输入选择keyword。此启发式仅决定检索方式，不代表问题已经被语义理解；不能识别所有事件表达。旧URL中的显式strategy仍被尊重，便于保留既有结果链接。自动选择的模式不写成固定URL模式，用户随后换问题时继续自动选择。范围、页码和返回搜索链接仍保留。

2项直接相关前端脚本验证通过（标点搜索接口与阅读首页），未启动浏览器/数据库/模型/桌面冒烟，未执行全量测试。同步调整源码中的桌面验收脚本以使用旧模式URL，不再依赖已移除的下拉框；本轮未执行该桌面脚本。桌面正常前端从项目文件读取，无需为界面变更重建EXE；此前语义修复仍待统一打包，不能据此称已更新冻结后端。

模型、召回、排序与原文没有改动，未声称准确率提升。本轮按授权commit/push，实际结果由最终回复报告。
