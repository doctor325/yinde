## 解释与边界

短算术输入此前两侧均正确，而本次完整史料输入出现明显差异。因此当前问题不能统一归因于“模型太小、不理解史料”，也没有依据继续围绕此故障改提示词。当前GPU配置不能用于验收或部署。

本次没有控制进程执行顺序、操作系统或驱动缓存状态；只完成每侧一次有限输出，不能宣称任意输入必现或所有GPU均有问题。原650-token请求没有完整重跑，复现的是相同输入下的早期重复特征；并非逐token完全复现旧输出。

日志中的控制token类型修正、禁用idle-slot缓存警告在两侧均出现，单靠这些共同警告不能解释差异。当前日志也不足以确认具体精度、attention实现、矩阵计算内核或驱动缺陷；不据此改驱动或认定某个上游问题就是根因。
