# 地点线索与当前事件绑定

evidence_pipeline.audit此前在整条主谓观察句中搜索于/在等介词，可能借用同句其他人物、其他动作的地点。本轮利用已存在的原文subject_span和predicate_span，只在当前谓语后、同一逗号分句内核查后置地点线索。

直接的“甲公即位於東宮”“乙侯卒于西城”可提供线索；“乙侯在东宫，甲公即位”“甲公即位，遂至东宫”不会据此填入地点。地点候选需要有限的地理/建筑后缀，并排除部分明显连接词和新动作。后缀只提供表面线索，不构成地名验证；前置地点、省略指代、无后缀专名与复杂句式保持未确认，可能漏识别。relation_verified仍为false，未测量真实检索准确率提升。

仅修改可选evidence方式的地点槽位核查，影响其线索优先排序信号；动作对象、因果和其他槽位留待后续。引文、模型、语料、gold与默认检索不变。桌面包待相关修复积累后统一更新。

验证范围：同一个地点模块单测命令共执行两次。首次发现传统介词“於”缺失，修复实现后5项测试通过；涵盖不同主体/事件、其他人物与动作的地点、跨观察句、原文偏移、否定传闻及未知句式。未改测试判据。没有模型评测、数据库、浏览器或桌面冒烟。另检查本轮文件差异。

建议后续验证：独立标注的小批真实地点句，检查保守后缀规则的误报与漏识别；本轮未运行。按持续授权提交并push，实际结果以最终回复为准。
