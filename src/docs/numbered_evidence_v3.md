# 编号证据输入压缩与分步记录

2026-11-14，基于776996c。本轮只修复隔离实验的输入冗余和失败记录，未改默认检索、
模型权重、原文、gold、判断守卫、120秒请求期限或桌面包。

## 修改

- 传给模型的证据改为`编号→原文`映射。身份开篇与不完整证据的编号各列一次；其余默认为
  完整事件上下文。来源块偏移、引用定位等仍完整保存在本地，模型不需要反复接收这些信息。
- JSON采用紧凑序列化，只去除结构空格，原文中的空白、标点、繁简字形均不变。
  编号生成函数未改，来源内容和选取范围与旧版本相同。
- 解析完成后立即保存输出、用量和耗时；第二步失败时保留第一步结果、失败阶段、异常类型、
  该阶段耗时与总耗时。异常不再丢失整次调用的诊断信息。
- 实验默认只运行`chenping_positive`；可显式指定另一个已曝光开发题。
  每次生成独立目录，保存输入上下文摘要、阶段记录和日志，不覆盖旧失败记录。
