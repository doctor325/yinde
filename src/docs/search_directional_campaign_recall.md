# 史书只写出兵方向时的劝谏召回

沈庆之问句指定北魏。《宋书》二十七年的劝谏在开头只写“太祖將北討”，现有传记召回要在附近找到用户指定的对象，因此漏掉了这段。上轮排第 1 的是二十九年再次议兵。它无法给出二十七年那次劝谏的理由。

向传记召回补入一条有原文约束的路径。传主的劝谏须紧接出兵提议，后文须以“及”承接同一个出兵表达，并在接续叙事中明确出现对手。三条索引片段须同书、同篇、同版、同正文层，且两处重叠原文相同。若叙事换年或另起出兵，停止沿用原来的提议。排序模型能同时读到劝谏开头和承接出兵的后文。卡片的相邻原文可以回查这一上下文。出兵方向和对手姓名只用于补充候选，仍需独立证据绑定所问政权。
