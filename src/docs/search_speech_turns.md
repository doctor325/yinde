# 劝谏对话的发言归属验证

上轮完整奏疏原型能判断房玄龄的上疏，仍漏掉沈庆之的当面劝谏。本轮先按原文标点识别外层发言，单独保存每人的发言边界，再从同一发言及紧邻叙事提取发言人、受议者、拟议行动和理由。最后才用这些字段回答问题。内嵌引语的文字被屏蔽，后续人物的答辩和下一次出兵各自保留在原位置。

| 原文 | 对照 | 现有判断 | 离线原型 |
| --- | --- | --- | --- |
| 《宋书》沈庆之，片段 44067–44069 | 劝宋文帝不要北讨 | 漏标 | 找到骑步不敌的理由 |
| 同一份《宋书》原文，包含宋文帝的答辩 | 互换劝谏者与受议者 | 尚未确认 | 尚未确认 |
| 《晋书》吕纂，片段 87240–87241 | 杨颖劝吕纂不要出兵讨伐秃发利鹿孤 | 漏标 | 找到对方部众听令、暂无可乘之机的理由 |
| 同一份《晋书》原文，包含姜纪的后续劝谏 | 互换双方、把姜纪对另一次出兵的意见套到前一次 | 均尚未确认 | 均尚未确认 |
| 《辽史》耶律铎臻，片段 243401–243402 | 劝辽太祖暂缓攻渤海 | 漏标 | 找到先攻渤海会遭西夏从后方进攻的理由 |
| 同一份《辽史》原文 | 互换双方、把渤海换成西夏 | 均尚未确认 | 均尚未确认 |

开发正例 1/1，独立正例 2/2，五道反题零误标。程序按固定修订、原文块和字符范围复核证据，并检查理由确实位于该发言者的引语内。杨颖和耶律铎臻两组在原型编写前冻结，本机冻结件 `src/data/speech-turn-holdout.json` 的 SHA-256 为 `49d5ff5fc02516ae9afbb0732475918775343b4e5b6ef0ea8420bc89796e5083`。

实验使用了人工核对的原文范围、人物称谓和行动对象映射，例如“庆之”“太祖”和“北讨”。结论限于这些输入已知时的发言归属，实际搜索仍需验证能否自动取得同一上下文与称谓依据，以及充分原文能否进前五。原型目前保留在验收目录。

从 `src` 运行 `python -B -X utf8 -m tests.evidence_acceptance.review_speech_turns`。版本、范围、校验值、查询与判据位于 `src/tests/evidence_acceptance/speech_turn_cases.json`。原文由本地标点库和索引读取。详细运行结果保存在本机 `src/data/speech-turn-review.json`。
