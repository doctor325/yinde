# 关系限定词作用范围实验任务汇报书

## 1. 任务概述

继续语义准确性优化，针对上一轮已知问题：扫描整句的“未／不／将”等字符会把另一分句的否定转移到当前事件。用户本轮明确授权今后每次优化完成后commit和push，已更新AGENTS.md。

## 2. 执行结果

新增独立离线模块relation_context.py，由调用方提供已识别的主体、谓词位置，再返回限定词及原文坐标。不承担人物识别，不推断历史真假，不删除候选；relation_verified始终为false。普通否定、情态限制在主体到谓词之间；传闻、条件引导词保守保留跨逗号作用；句号等硬边界阻断前句影响；主谓间若跨分句则标为unresolved_scope。

例如“甲公卒，援军未至”和“援军未至，甲公卒”不把“未”转给“卒”；“传言军败，甲公卒”保留reported；“将军甲公卒”不把官称“将军”解释为未来。均为合成语言测试，不是历史陈述。

本次**未接入线上排序、未重建或更新桌面包**。当前桌面仍为上一轮ed70e921版本。完成的是可独立复现的小范围实验，不宣称用户检索准确性已经提高。

## 3. 证据与实测数据

- 9项新单元测试通过，含4个合成主体×3种邻句否定布局，以及直接否定、传闻、假设、句界、官称、作用范围不明和原文坐标检查。
- 既有55项标点相关测试通过；未改变原有18组角色反例、30条历史证据gold及旧判据。
- 无真实语料准确率、Top-K或性能改善数据。本模块输入主体位置仍依赖调用者，不可把其测试通过当作关系理解通过。
