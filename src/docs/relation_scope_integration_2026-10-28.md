# 主谓限定词作用范围：真实候选验证与集成报告

## 1. 任务概述

承接上一轮离线限定词模块，验证真实候选中的误判并接入工作区可选关系实验的句式模块。默认关键词、语义和增强检索路径未改；本轮不更新桌面安装包。

## 2. 执行结果

完成subject/predicate显式命名捕获与原文坐标映射；去空白、简繁查找转换后的证据仍还原到原文位置。限定词模块现在要求subject_end，避免把人名内部的“无、若、莫”等字符解释为否定或假设。前置愿望、使令仍保守标记；明确任职“命某人为某官”单独保留句式信号，“欲命某人为某官”不作同样处理。

punctuated_roles只依赖已跟踪的zh和relation_context，取消对未提交搜索管线的无用依赖。生产关系实验在源码层已有该模块导入，因此源码运行可使用新逻辑；正式安装EXE仍是前轮版本，不宣称已经部署到用户窗口。

## 3. 证据与实测数据
