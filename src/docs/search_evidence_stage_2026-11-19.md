# 史料检索与证据判断阶段验收

本次阶段全量包含此前冻结的 13 题和 [四条新史料对照](../tests/evidence_acceptance/advocacy_holdout.json)。新题在运行搜索前固定引文及偏移。统一搜索表单经本机桌面服务访问正式标点索引和本地重排模型。每题核查候选是否包含可作答原文、前五展示、所有线索标记及相邻原文。秦至明的全时期覆盖另按君主名录与随机样本验收。

## 原因证据

- 赵充国题的《汉书》片段 57945 第 1。当前段提出“今留步士萬人屯田”，同一奏议说明“屯田內有亡費之利，外有守禦之備”。相邻同版本片段 57944 的“充國奏曰”提供发言者依据。标记保留发言者、提案和理由的原文偏移。
- 裴度题的《旧唐书》片段 221138 第 1。段首“自討淮西”绑定省略目标的“遂堅請討伐”。本传先写论者认为伤亡多、转运不继，随后写裴度担心久拖成患及两河效尤。标记落在裴度的理由，来源归为史书叙述。
